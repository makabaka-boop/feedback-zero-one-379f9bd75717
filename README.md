# 图查询引擎

从零实现的内存图查询后端，仅依赖 Python 标准库 `json`，核心求值全部自写。

## 运行

需要 Python 3.7+，无第三方依赖。

```bash
# 文件入参
python3 -I engine.py sample_basic.json

# 标准输入
cat sample_basic.json | python3 -I engine.py
```

成功时把结果数组打印到标准输出，退出码 0；预检失败时把错误 JSON
打印到标准错误，退出码 1。

```
{"error": "...", "path": "$.query[2][0]"}
```

## 输入格式

JSON 顶层对象只允许两个成员：

```json
{
  "triples": [["a", "p", "b"]],
  "query":   ["scan", "?x", "p", "?y"]
}
```

- **常量**：非空 ASCII 字符串，且不以 `?` 开头。
- **变量**：`?` 后接一个或多个小写字母（如 `?x`、`?name`）。
- 三元组三个位置都是常量；整个 `triples` 数组先去重再建图。
- 顶层若出现重复键（如两个 `triples`）整次请求被拒绝。

## 查询节点

| 节点 | 含义 |
| --- | --- |
| `["scan", s, E, o]` | 模式匹配；`s`、`o` 为变量或常量，`E` 为谓词或路径 |
| `["join", A, B]` | 左右独立求值，兼容映射合并，重数相乘 |
| `["optional", A, B]` | 左结果逐个传入右侧；有匹配则扩展，无匹配保留左结果 |
| `["filter", A, F]` | 逐行求过滤器，仅保留真值 |

### 路径表达式 E

- 谓词常量：单步出边。
- `["/", E1, E2]`：中间点连接，各路线多重数**相乘**。
- `["|", E1, E2]`：两条路径结果并列，多重数**相加**。
- `["*", E]`：取**可达端点集合**（去重，每个端点重数 1）。
  零步只包含图中实际出现的主/客体节点；起点不在图中时没有零步。

### 过滤器 F（首项为标签的数组）

| 过滤器 | 规则 |
| --- | --- |
| `["eq", a, b]` | 相等判断；任一变量未绑定为**错误** |
| `["bound", v]` | 只查当前映射中是否绑定该变量 |
| `["exists", Q]` | 把当前映射传入子查询 Q，非空为真；内层绑定不向外泄漏 |
| `["not", F]` | 真↔假，错误保留为错误 |
| `["and", F1, F2]` | 有假即假（**假压错**），否则含错为错 |
| `["or", F1, F2]` | 有真即真（**真压错**），否则含错为错 |

三值逻辑：真 / 假 / 错误。`filter` 只保留结果为真的行。

## 映射与输出

- 映射 μ 是变量到常量的绑定；两个映射在同名变量上同值才**兼容**。
- 顶层映射为空映射。
- 每个输出行是 `[变量, 值]` 数组的数组，变量按 ASCII 序排列，
  未绑定变量不占项；重复结果保留。
- 外层结果按数组字典序排列；空结果为 `[]`。

题面样例：图 `[["a","p","b"]]` 上查 `["scan","?x","p","?y"]` 输出

```json
[[["?x", "a"], ["?y", "b"]]]
```

## 预检与错误路径

求值前对整棵树做预检，任何非法结构、非法字符串或重复成员都会
**整次拒绝**（不会部分求值）。错误 JSON 中的 `path` 为出错位置的
JSON 路径，数组下标零基；JSON 语法错误的路径固定为 `"$"`。

```
$.triples[0][2]      # 第一个三元组的客体非法
$.query[2][1]        # filter 节点的过滤器参数非法
$.query[1][2][0]     # 嵌套路径的标签非法
$.triples[1]         # 根对象重复成员 "triples" 的第二次出现
```
